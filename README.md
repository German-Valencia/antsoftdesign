# ANT Soft Design

Sitio web de ANT Soft Design desarrollado con Next.js (Pages Router), React y CSS Modules.

## Requisitos

- Node.js 20.9 o superior
- npm

## Desarrollo

```bash
npm ci
npm run dev
```

La aplicación queda disponible en <http://localhost:3000>.

## Verificaciones y producción

```bash
npm run lint
npm run build
npm start
```

`npm start` sirve la compilación de producción generada por `npm run build`.

## SEO

Las URLs canónicas, el sitemap y `robots.txt` usan el dominio público
`https://antsoftdesign.vercel.app`. Actualiza esos valores si cambia el dominio.
